What this does

Turn a research question into a cited brief.

Enter a topic and bb research engine runs a repeatable evidence pipeline: discover sources, extract usable evidence, synthesize the answer, then verify confidence before showing the final result.

Pipeline details

Six static steps from planning to verified output.

01 Planning

Clarifies the question, source strategy, and quality rubric before any web calls run.

02 Search

Discovers candidate URLs quickly while preserving titles, links, and result context.

03 Fetch

Retrieves page content first, avoiding browser-session cost when static content is enough.

04 Browser

Uses Stagehand only when a source is dynamic, blocked, thin, or needs rendered-page extraction.

05 Synthesis

Turns accepted evidence into findings, source records, gaps, contradictions, and follow-up questions.

06 Verify

Scores source coverage, missing angles, confidence signals, and process quality so uncertainty stays visible.
